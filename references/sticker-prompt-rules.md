# 表情包提示词技术规范 · sticker-prompt-rules

> 对 SKILL.md 第四节的补充：聚焦"一套表情如何保持统一、240 方图如何落地、文字如何处理"三个工程问题。

---

## 一、一致性三策略（按可靠性排序）

| 策略 | 做法 | 一致性 | 适用 |
|------|------|--------|------|
| **A. 图生图（最强）** | 提供 IP 参考图，生图时作为 `image` 入参，提示词用 `same character as the reference image` | ★★★★★ | 有参考图必用 |
| **B. 风格前缀锁（中）** | 无图时，6 风格前缀表（见 SKILL.md 第三节）写进每条提示词开头，固定外观 | ★★★★ | 只有风格/描述 |
| **C. 同段描述锁（中）** | 用户给了具体角色描述（如"戴眼镜橘猫"），该段描述原样写进每条提示词 | ★★★★ | 有文字描述 |

**铁律**：12 张里**角色外观描述必须逐字相同**，只改"动作/表情"部分。任何外观词的细微差异都会被绘图模型放大，导致"不像同一只"。

---

## 二、240×240 方图落地

- **生图阶段**：ImageGen 不直接接受像素尺寸，用比例约束——提示词含 `square composition`，生图后由 `assemble.py` 统一缩放到 **240×240**（LANCZOS 高质量重采样）。
- **为什么先大后缩**：直接生成 240px 会损失细节；先生成 1024 级别再缩，描边和五官更干净，缩放后小图更锐利。
- **正方形裁剪**：若生图非严格 1:1，`assemble.py` 用**居中裁剪到正方形**再缩，确保每张都是正 240×240。
- **背景处理**：默认 `transparent background or clean solid color`；若实际生成带复杂背景，`assemble.py` 可叠加纯色底（白/主题色），但无法完美抠图——所以提示词务必强调 `isolated subject, easy to cutout`。

## 三、文字处理（核心坑）

| 方案 | 做法 | 清晰度 | 推荐度 |
|------|------|--------|--------|
| **烤进贴纸内部（默认）** | 图内 `no text`，文案用 `assemble.py` 烤进 240×240：白字 + 黑描边、贴底居中、自动字号 | 清晰可控，最贴近真实表情包 | ★★★★★ |
| 提示词画字 | 提示词写 "with Chinese text 收到" | 极易乱码/错字 | ✗ 不推荐 |
| 半透明条烤字（旧版，已弃用） | 在贴纸底部贴半透明黑条 + 白字 | 文字清晰但会遮挡角色 | ✗ 不再默认 |

- **字体优先级**：`msyhbd.ttc`（微软雅黑 Bold，贴纸更醒目）→ `msyh.ttc` → `simhei.ttf` → `simsun.ttc`；脚本自动查找，找不到回退 PIL 默认。
- **默认位置 / 样式**：图内底部、水平居中、距底约 10px、白字 RGB(255,255,255) + 黑描边 RGB(0,0,0) 宽 3px、字号 16-42px 自适应。
- **若要纯图**：加 `--no-text` 参数跳过烤字。
- **字数**：单张文案建议 ≤ 6 字，超过在小尺寸下糊成一团。长文案拆成短句或放预览图说明。

## 四、各风格表情包微调建议

| 风格 | 表情包特别提示 |
|------|----------------|
| 萌系 | 表情幅度放大 1.5-2 倍（参见 ip-design 萌系情绪公式），小尺寸才看得清情绪 |
| 潮酷系 | 用非对称表情（挑眉/歪嘴），动作带态度；背景用纯黑/撞色更酷 |
| 国风系 | 表情幅度收敛（原典气质），动作含蓄；文案用文言/半文半白更贴 |
| 极简系 | 用几何化情绪（见 ip-design 极简情绪表），色 ≤3，缩小到 16px 仍可辨 |
| 暗黑系 | 阴影占比高，但表情包要"萌系暗黑"平衡，避免真吓人；适合万圣节主题 |
| 治愈系 | ω 嘴 + 半闭眼 + 腮红三件套；暖色，看了舒服 |

## 五、质量自检清单（生图后）

- [ ] 12 张是否为**同一个角色**（图生图锚定 / 前缀一致）
- [ ] 是否全部**正方形**、主体居中、无裁切
- [ ] 背景是否纯净（无杂乱元素，便于抠图/透明）
- [ ] 是否**静态**、无运动模糊
- [ ] 是否**无图内 AI 文字**（文字由 assemble.py 烤入，非 AI 画）
- [ ] 烤字是否清晰（不遮挡主体表情、字号合理、不被截断）
- [ ] 缩到 240×240 后，表情是否仍 2 秒可读
- [ ] 文案与画面情绪是否匹配
